发现的误报

① 会话名变成日程标题

QQ 通知的 EXTRA_TITLE 是 always online(2条新消息) —— 19 个字符，超过上一版设的 16 字阈值，所以没被识别成"发送人"。
修复前修复后
日程标题 always online 宣传部培训通知
原文 always online(2条新消息) 📢【宣传部培训通知✨】@所有人…宣传部将于10月25日（周日）晚上18:30…

修法：标题里出现 (N条新消息) 这种未读数尾巴，直接判定为通知栏摘要，不再看长度。

② 游戏营销推送被建成日程

小王同学 🔥 王者荣耀2026周年庆，10月24日登录游戏领好礼！【登录就送】
里面确实有「10月24日」，但这是广告，不是要你去做一件事。

修法：加营销词识别（登录就送 / 领好礼 / 优惠券 / 秒杀 …），命中且没有明确时间点就放过。「明天下午3点参加抽奖活动」这种真行程不会误伤。

这几行是应用内置的「处理日志」自己记录的 —— 诊断模式打开后，每个回调都会留痕，包括被判为不相关而跳过的。排查误报时不用猜，直接看它走了哪条分支。

仍未覆盖

项状态原因
通知栏「确认 / 删除」按钮 未验证 需要生成「待确认」状态的通知，模拟器上没有能稳定触发的源
重复日程拦截 未验证 需要输入中文标题，adb input text 不支持中文
后台保活 未验证 模拟器没有厂商 ROM 的杀后台策略，测了也不代表真机
真实微信 / QQ 通知 未验证 模拟器抓到的 QQ 通知来自系统镜像自带的测试数据
Android 13+ 通知权限 未验证 API 28 没有 POST_NOTIFICATIONS 运行时权限

复现方法

调试时用的关键命令，下次可以直接抄。

# 装包（覆盖安装，数据保留）
adb install -r dist/smart-schedule-v1.16-debug.apk

# 抓界面层级（注意 Git Bash 下要关路径转换，否则 /sdcard 被改写）
export MSYS_NO_PATHCONV=1
adb shell uiautomator dump /sdcard/ui.xml
adb pull /sdcard/ui.xml ./ui.xml

# 点击 / 长按 / 滑动
adb shell input tap 540 1286
adb shell input swipe 540 1000 540 1000 900      # 原地按 900ms = 长按
adb shell input swipe 540 1400 540 600 300       # 上滑

# 截图（图片内容识别被拦时，用 uiautomator dump 代替）
adb exec-out screencap -p > shot.png
一个坑：Git Bash 会把 /sdcard/ui.xml 当成路径自动转成 D:/Program Files/.../sdcard/ui.xml，导致 adb pull 找不到文件。 加 export MSYS_NO_PATHCONV=1 即可。
